The Manrope 400 and 700 TTF files are static weight instances derived from the existing `manrope.ttf` variable font using fontTools varLib.instancer. They retain the Manrope Project's original SIL Open Font License in OFL.txt. They are used for PDF text rendering; the website keeps its existing variable font. Financial PDFs render explicit ISO currency codes because this font does not contain every currency symbol.
